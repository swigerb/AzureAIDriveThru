### Key Learnings

1. **Factory-registered HttpClient logging:** `AddHttpClient(name)` wires up logging by default. Must call `.RemoveAllLoggers()` to match original bare client behavior.

2. **Reviewer-rejection lockout protocol works:** Beth locked out, escalation specialist (non-roster) brought in, fixed both blocking issues, Rick approved re-review. Clean separation of concerns.

3. **"Why" comments vs. "History" comments:** Clear precedent set — comments should explain design decisions ("why"), not narrate PR/issue history ("what was decided where").

4. **SessionSweepService closure capture:** Closure-capture pattern for late-bound dependency (`sessionManager` assigned after factory registration) is safe when factory is never invoked before assignment.

5. **FireAndForget helper as observability:** Small utility (observes discarded tasks, logs faults, skips cancellation) unifies error handling across 7 fire-and-forget sites with minimal code duplication.
