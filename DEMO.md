# Demo quick-start

Run these commands from the repository root before presenting the experience live:

```powershell
azd auth login
./scripts/start.ps1
```

On macOS or Linux, use `./scripts/start.sh`.

## Demo Mode

Open **Settings** and turn on **Demo Mode**. If the active persona ships `assets/demo/guestScript.json`, the center controls show **Run demo: This brand** and **Full tour**. The demo starts a fresh order, feeds a synthetic mic stream with the scripted guest clips, plays the Ava guest voice to the room, and advances only after assistant playback has been quiet long enough for a complete turn. Use **Stop demo** to end the conversation cleanly.

Production server VAD ends a guest turn after 200 ms of silence. Guest clips generated by `scripts/generate_demo_guest_voice.py` trim leading and trailing silence and cap internal pauses at 120 ms so one scripted line stays one turn. The demo runner adds a 300 ms lead and 900 ms tail to each clip.

## Taco Bell rewards demo

Select **Taco Bell** (or open `?persona=tacobell`). If `PERSONAS` is configured explicitly,
include `tacobell` in its list. All menu prices and 8% tax are samples, not restaurant 036309
quotes. Keep **Dummy Data** off to use the real session's simulated rewards panel.

Enter **DEMO-PLUS** to check in with 500 fictional points, or **DEMO-NEW** to start at zero.
Never enter a real rewards number or code. Order two plain Crunchy Tacos, then select
**Redeem demo reward**: one taco is covered for 250 demo points. Select **Complete demo
order** to commit the reservation and award points once; it does not place a purchase.
The sample two-taco order earns 19 points after redemption, leaving 269 fictional points.
Reloading resumes the same ticket and ledger. **Start next demo order** clears the ticket
but retains the session-only balance; ending the session discards it.

For branding, source dates, authorized-logo provenance, font substitutions, sample pricing
and actual-program versus simulation limits, see [the Taco Bell source note](personas/tacobell/SOURCES.md).
